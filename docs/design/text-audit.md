# Text audit

Every player-facing string checked against `glossary.md` (the style rules and terms). This round writes documents only; the rewrites are applied after the parallel UI work merges. "Tip key" means a key of `tips` in `apps/web/src/text/tips.ts` (the wiki's icon page is built from the same table, so one fix there fixes both). Rewrites use `{placeholders}` for numbers (rule 11); where the placeholder does not exist in `tipValues.ts` yet, it is added with the rewrite.

**Scope.** About 330 strings were read: 181 tip texts (and their titles), 30 skill nodes, 26 button verbs, about 75 content names (roles, stances, features, threats, terrains, items, materials, lures, hazards, settlements), 4 intro cards, 5 role-card lines, 5 hints, 5 practice captions, the day menu, the ending titles, the wiki headings and note, and the recap labels. Story beats and ending lines (`story.ts`) are prose and were read for glossary clashes only (none block: "village" and "hill folk" are fine in story). Moments have no text. Row counts are at the end.

**Reading the table.** "Rule" is a glossary style rule number (S1 to S13) or a term clash (T: term). "Fact?" marks a rewrite that needs a fact the code does not settle.
