# Research: terrain colours (2026-11-24)

Evidence thin (snippets only); per-game colours from the researcher's knowledge; the palette is a proposal to tune by eye.

Seen: Meeple Like Us Catan accessibility teardown (terrain palette weak; reds/greens blur for protan/deutan); colour-blind review of Cascadia; advice to double-code colour with icons; cartographic illustration advice (contrast directs attention); muted palettes with darker accents; atmospheric depth (distance tinted blue-green).

How board games do it (unconfirmed): Catan — forest dark green, pasture light yellow-green, fields yellow, hills orange-red, mountains grey, desert cream; forest vs pasture by value. Carcassonne — shape and prop carry type. Kingdomino — wheat yellow, forest dark green, lake blue, grass light green, swamp grey-brown, mine dark brown, each with a strong prop; swamp is the muddy, desaturated one. Cascadia — mountain grey, forest dark green, prairie yellow, wetland teal-green, river blue, with icons as safeguard. Common pattern: neighbours differ in value first, then hue; each terrain has a prop or texture.

Principles: settle value first (greyscale test; pairs ~8–10 L* apart); one hue family per terrain, at most two greens; "broken" colour (mix toward the complement) for lively pastels; water the only saturated cool blue; paths and trodden ground a warm light; distance/fog via one overlay, not base fills; one dark ink line across all terrain; double-code with props (red–green is the main colour-blind risk).

Proposed palette (fill / shade / accent; cue):

- Plains #E6E2A8 straw-cream / #CBC884 / #9DB35A — short grass ticks and tiny flowers; no trees.
- Forest #7FA87A sage / #4F7F5E deep teal-green / #2F5A47 — round tree clusters; darkest green.
- Desert #F0D2A0 warm sand / #D9AE72 / #C98A4E — dune ripples; lightest and warmest.
- Cliffs/rock #BDB8C4 lilac-grey / #8E8A9E / #5E5A70 — angular facets, hard hatching.
- River/water #A9D0E0 / #6FA6C4 / #3E7FA3 — wavy lines, flow ticks; the only cool blue.
- Swamp #A89A72 muddy tan-olive / #7F7550 / #4E5E3C dark green — reed tufts, murky puddles, stubby dead trees; brown-dominant.
  Value order lightest→darkest: desert, plains, water, rock, forest, swamp. Check swamp vs desert in a colour-blind simulation.

Overlays: veiled = warm paper-white wash ~55–65 % (#F3EEE0), soft edge, grain; reveal by fading the wash. Trodden = #E8D3A2 ~70 % with a thin darker edge (#B99A62), dashed footprints or path stroke; on desert and plains add a darker outline or dotted pattern; on water show a ford/bridge prop.
